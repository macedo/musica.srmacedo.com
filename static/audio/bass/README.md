# Samples de baixo

Notas do baixo "Dark Black" da biblioteca [Black And Blue Basses](https://github.com/sfzinstruments/karoryfer.black-and-blue-basses),
da Karoryfer Samples, distribuída sob **CC0 1.0** (domínio público, sem exigência de
crédito). O crédito aqui é por cortesia.

Articulação normal (`Samples/darkblack/reg`), intensidade `mf`, primeira repetição
(`rr1`). A biblioteca nomeia as notas uma oitava acima do som real; aqui os arquivos
têm o número MIDI do som real:

| Arquivo  | Nota | Original                        |
|----------|------|---------------------------------|
| `28.wav` | E1   | `darkblack_e2_mf_rr1.wav`       |
| `31.wav` | G1   | `darkblack_g2_mf_rr1.wav`       |
| `34.wav` | B♭1  | `darkblack_bb2_mf_rr1.wav`      |
| `37.wav` | D♭2  | `darkblack_db3_mf_rr1.wav`      |
| `40.wav` | E2   | `darkblack_e3_mf_rr1.wav`       |
| `43.wav` | G2   | `darkblack_g3_mf_rr1.wav`       |
| `46.wav` | B♭2  | `darkblack_bb3_mf_rr1.wav`      |
| `49.wav` | D♭3  | `darkblack_db4_mf_rr1.wav`      |
| `52.wav` | E3   | `darkblack_e4_mf_rr1.wav`       |

Processamento: cortados a partir do ataque, 2 s com fade-out cosseno, filtro
passa-baixas (FIR, 9 kHz) e reamostragem para 22,05 kHz, mesmo ganho em todas as
notas (pico máximo -1 dBFS). WAV 16-bit mono.
