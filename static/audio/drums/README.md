# Samples de bateria

Batidas acústicas da [Karoryfer Samples](https://karoryfer.com/) (Big Rusty Drums e
Szpaderski), obtidas no [Stargate sample pack](https://github.com/stargatedaw/stargate-sample-pack)
(pasta `stargate-sample-pack/karoryfer`), que é distribuído sob **CC0 1.0** (domínio
público, sem exigência de crédito). O crédito aqui é por cortesia.

| Arquivo         | Original                          |
|-----------------|-----------------------------------|
| `kick.wav`      | `kicks/kick_Szpaderski_24_dampened.wav` |
| `snare.wav`     | `snares/snare_12x5.wav`           |
| `hat.wav`       | `hihats/hihat_BRD_closed.wav`     |
| `hat-tight.wav` | `hihats/hihat_BRD_tight.wav`      |
| `crash.wav`     | `cymbals/crash_BRD_17.wav`        |
| `ride.wav`      | `cymbals/ride_BRD_22.wav`         |

Processamento: mixados em mono, cortados a partir do ataque, encurtados com
fade-out cosseno e normalizados para -1 dBFS (WAV 16-bit, 44,1 kHz).
